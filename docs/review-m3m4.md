## 2. 产品（PM）视角核对与排期观察
1. **任务硬关联缺失（排期 V2）**：Task 模型无 `session_id`，页面“任务联动”采用回复文本正则提取（尽力而为，DOM 已验证当文本含任务 id 时生效）；产品级“我在这轮对话创建的任务”需后端在 generate/optimize 落任务时回写会话，建议 V2 数据模型小步。
2. **对话同步无流式**：`/chat` 为一次性 POST，长生成体感卡顿；流式/SSE 已在规划 V1.5，验收期建议先声明。
3. **会话历史全量回读**：长会话将拖慢详情接口；V1.5 建议消息分页/截断。
4. **快捷示例含演示 uid**：非 demo 部署点击会报“目标不存在”；建议示例改为通用话术或取真实实例名（低）。
5. **LLM 健康指标**：设置页为静态说明；若需“熔断中”实时状态需后端暴露指标端点（V1.5 可选）。
6. **Playwright 真浏览器冒烟仍未落地**（环境未装浏览器，PRD §9 质量门槛）——建议 **V1 GA 前作为必做门禁**，覆盖 Dashboard 统计/引导弹窗/对话发送/审批按钮等 DOM 冒烟场景。
7. 文案仍为中文主文案（EN 骨架后续 V2）。
